# Tager

OSM editor for refining objects.

The project was fully generated by an LLM.

## Installation

1. Install dependencies:
```bash
npm install
```

2. Create a `.env` file in the project root and set the variables:
```env
VITE_OSM_OAUTH_CLIENT_ID=your_client_id
VITE_OSM_OAUTH_REDIRECT_URI=http://127.0.0.1:5173/login
```
Optionally — Mapbox satellite tiles:
```env
VITE_MAPBOX_ACCESS_TOKEN=your_token
```

3. OAuth application on OpenStreetMap:
   - https://www.openstreetmap.org/user/your_username/oauth_clients
   - Create an application, set Redirect URI: `http://127.0.0.1:5173/login` (for development)
   - For GitHub Pages: `https://your-username.github.io/tager/login`

4. Run:
```bash
npm run dev
```

Build and preview:
```bash
npm run build
npm run preview
```

## Usage

1. Sign in via OpenStreetMap OAuth.
2. On the search page, select an area on the map and click "Load objects".
3. On the edit page:
   - Choose a tag value from the list or enter your own (multiple values — via checkboxes).
   - "Confirm and continue" — go to the next object.
   - "Finish" — save changes to OSM.
