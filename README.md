# OSM Sport Tag Editor

SPA приложение для уточнения тега `sport` для объектов OpenStreetMap с `leisure=pitch` и без тега `sport`.

## Возможности

- Авторизация через OpenStreetMap OAuth 2
- Поиск местности на интерактивной карте
- Загрузка объектов через Overpass API
- Редактирование с 4 синхронизированными картами (OSM, Esri Satellite, Esri Topo)
- Форма выбора популярных значений тега sport
- Генерация и выгрузка OSM Change XML

## Установка

1. Установите зависимости:
```bash
npm install
```

2. Создайте файл `.env` на основе `.env.example`:
```bash
cp .env.example .env
```

3. Зарегистрируйте OAuth приложение на OpenStreetMap:
   - Перейдите на https://www.openstreetmap.org/user/your_username/oauth_clients
   - Создайте новое приложение
   - Укажите Redirect URI: `http://localhost:5173/login` (для разработки)
   - Скопируйте Client ID и Client Secret в файл `.env`

4. Запустите приложение:
```bash
npm run dev
```

## Использование

1. Войдите через OpenStreetMap OAuth
2. Найдите интересующую местность на карте
3. Нажмите "Загрузить объекты" для загрузки объектов `leisure=pitch` без тега `sport`
4. На экране редактирования:
   - Используйте 4 синхронизированные карты для просмотра объекта (OSM, Esri Satellite, Esri Topo)
   - На всех картах отображается контур текущего объекта
   - Выберите значение тега `sport` из списка или введите свое (можно выбрать несколько через чекбоксы)
   - Нажмите "Подтвердить и продолжить" для перехода к следующему объекту
   - Нажмите "Завершить" для генерации и выгрузки OSM Change XML файла

## Структура экрана редактирования

Экран разделен на 4 квадрата:
- **Левый верхний**: Leaflet карта с подложкой OSM
- **Левый нижний**: Leaflet карта с подложкой Esri Satellite
- **Правый верхний**: Leaflet карта с подложкой Esri Topo
- **Правый нижний**: Форма с чекбоксами популярных значений sport и кнопки управления

Все карты синхронизированы - при перемещении или масштабировании одной карты остальные автоматически синхронизируются.
